# Pilot App Store distribution

`pilot.app.yaml` is the As Decided-owned input to Pilot Protocol's official
`pilot-app` generator. Core keeps the curated method mapping and product claims;
it does not vendor or maintain Pilot's generated IPC adapter.

The generated app is `io.pilot.asdecided`. It installs the release-pinned native
`decided` binary and exposes only:

- `asdecided.help` (generated by Pilot)
- `asdecided.retrieve`
- `asdecided.validate`
- `asdecided.relationships`

There is no arbitrary CLI passthrough and no mutation method. Validation runs
with `--no-cache`. The manifest declares read access to `$HOME` because Pilot
grants are fixed at installation while every call supplies its repository path.
The installer sees and consents to that authority; repositories remain local to
the Pilot node.

## Generate a release candidate

Use the current official `pilot-app` generator:

```sh
pilot-app validate -c distribution/pilot/pilot.app.yaml
pilot-app init -c distribution/pilot/pilot.app.yaml -o /tmp/asdecided-pilot
```

The publisher key named by the spec is deliberately not stored in this
repository. A catalogue submission is allowed only after the generated bundle
verifies and a real Pilot node passes install, help, and deterministic retrieval
against a local fixture, as required by ADR-125.
